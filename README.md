# NCSS-Nav 校园导航

> **🌐 可定制的校园服务聚合平台**
>
> **🏷️ 当前版本：v1.3.0**

模块化、可拼接的校园导航单页应用，支持一键换校适配。源自福建师范大学 FJNU-Nav 项目。

## ✨ 特性

- **模块化设计**：每个应用独立注册，支持热插拔
- **一键换校**：运行 `python customize.py` 即可适配新高校
- **主题定制**：内置多套配色方案，支持自定义主题
- **数据驱动**：静态数据与实时数据结合，支持离线使用

## 技术栈

- **前端**：Vue 3 + Vite，路由懒加载
- **数据源**：公开API + 爬虫 + 静态数据
- **部署**：GitHub Pages（自动构建）

## 一键换校

```bash
# 交互式输入
python customize.py

# 从配置文件导入
python customize.py --config templates/pku.json
```

## 本地运行

```bash
npm install
npm run dev
```

## 目录结构

```
NCSS-Nav/
├── src/
│   ├── config/site.js      # 站点配置（换校入口）
│   ├── router.js           # 路由（懒加载）
│   ├── data/               # 静态数据
│   ├── views/              # 应用页面
│   └── components/         # 可复用组件
├── customize.py            # 一键换校脚本
├── templates/              # 配置模板
│   └── pku.json           # 北京大学配置示例
├── crawler/                # Python爬虫
├── public/data/            # 静态数据快照
└── .github/workflows/      # CI/CD
```
