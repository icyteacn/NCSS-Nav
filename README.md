# NCSS-Nav 模块化校园导航平台

> **🌐 可定制的校园服务聚合平台**
>
> **🏷️ 当前版本：v1.3.0**
>
> **🔧 GitHub Actions：[![deploy](https://github.com/icyteacn/FJNU-Nav/actions/workflows/deploy.yml/badge.svg)](https://github.com/icyteacn/FJNU-Nav/actions/workflows/deploy.yml)**

模块化、可拼接的校园导航单页应用，支持一键换校适配。源自福建师范大学 FJNU-Nav 项目。

## ✨ 特性

- **模块化设计**：每个应用独立注册，支持热插拔
- **一键换校**：运行 `python customize.py` 即可适配新高校
- **主题定制**：内置多套配色方案，支持自定义主题
- **数据驱动**：静态数据与实时数据结合，支持离线使用
- **产业价值洞察**：涵盖校园卡代理、表白墙经济、校园广告等完整产业链分析
- **本站舆情统计**：用户增长、功能排行、设备分布、流量来源等数据可视化

## 📊 产业价值应用详解

产业价值应用包含 **7个子模块**，全面分析高校校园产业生态：

### 1. 市场概览
- 校园市场规模：约 1,200 亿/年
- 年增长率：15-20%
- 数字化渗透率：92%
- 市场结构分布可视化

### 2. 校园卡代理
- 四级代理体系：学生代理→校园代理→区域代理→省级代理
- 三大运营商校园卡对比
- 佣金结构与收入潜力分析

### 3. 表白墙经济
- 六大收入来源：表白投稿、广告推送、商品推广等
- 平台对比：微信公众号、QQ空间、抖音、小红书
- 月收入潜力分析

### 4. 校园广告
- 六类广告主：培训机构、驾校、考研机构等
- 投放渠道与投资回报率分析
- 投放高峰期预测

### 5. 新生服务
- 五大服务类别：生活用品、通讯服务、数码产品、教育培训、生活服务
- 利润率与目标人群分析
- 服务高峰期预测

### 6. 数字校园
- 六大平台：校园外卖、二手交易、跑腿服务等
- 用户规模与月流水分析
- 商业模式解析

### 7. 创业指南
- 六步创业路径：发现需求→验证想法→组建团队→获取资源→正式运营→规模化
- 创业资源与风险提示
- 学生创业实战经验

## 🔧 一键换校

```bash
# 交互式输入
python customize.py

# 从配置文件导入
python customize.py --config templates/pku.json
```

## 🛠️ 技术栈

- **前端**：Vue 3 + Vite，路由懒加载，首屏JS 97KB
- **数据源**：公开API + 爬虫 + 静态数据
- **部署**：GitHub Pages（自动构建）
- **CI/CD**：GitHub Actions 自动化

## 📁 目录结构

```
NCSS-Nav/
├── src/
│   ├── config/site.js      # 站点配置（换校入口）
│   ├── router.js           # 路由（懒加载）
│   ├── data/               # 静态数据
│   │   ├── apps.js         # 应用注册表
│   │   ├── industryValue.js # 产业价值数据
│   │   └── siteSentiment.js # 本站舆情数据
│   ├── views/              # 应用页面
│   │   ├── IndustryValue.vue # 产业价值应用
│   │   └── SiteSentiment.vue # 本站舆情应用
│   └── components/         # 可复用组件
├── customize.py            # 一键换校脚本
├── templates/              # 配置模板
│   └── pku.json           # 北京大学配置示例
├── crawler/                # Python爬虫
├── public/data/            # 静态数据快照
└── .github/workflows/      # CI/CD
    ├── deploy.yml          # 自动部署
    └── snapshot.yml        # 数据更新
```

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/icyteacn/FJNU-Nav.git
cd FJNU-Nav

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
